Entry for the make.fun bounty "The One-Line Cat Joke That Lands": a tiny Node program with no dependencies that writes a single one-line joke about a cat to `/output/entry.txt` — nothing else.

## Run it

```sh
npm start
```

or directly:

```sh
node main.ts
```

This writes the joke (one line, under 200 characters, no trailing newline) to `/output/entry.txt`.
